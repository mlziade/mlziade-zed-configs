# mlziade-zed-configs

Personal configuration files for the [Zed](https://zed.dev) editor

## Files

### `settings.json`
Main Zed editor settings — theme, fonts, terminal, soft wrap, inlay hints, edit predictions, agent sidebar, and auto-install extensions.

### `tasks.json`
Custom task definitions for Zed's task runner — currently defines a task to open Git Bash.

- [Zed Extensions](https://zed.dev/extensions) — browse and install extensions for Zed
